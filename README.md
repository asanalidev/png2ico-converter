# PNG to ICO Browser Converter

Простой, быстрый и полностью клиентский конвертер из формата PNG в `.ico`, который работает прямо в браузере. Без серверной обработки, регистрации и загрузки файлов на сторонние сервера — вся магия происходит локально с помощью HTML5 Canvas и JavaScript.

## 🚀 Возможности

* **Мгновенная конвертация** — обработка файлов занимает доли секунды.
* **Полная конфиденциальность** — ваши картинки не покидают устройство.
* **Мультиразмерность** — автоматическая упаковка нескольких размеров (16x16, 24x24, 32x32, 48x48, 64x64, 256x256) в один валидный файл `.ico`.
* **Drag-and-Drop** — удобное перетаскивание файлов мышкой.
* **Один файл** — весь проект умещается в один `.html` файл, что делает его невероятно простым в запуске и деплое.

## 🛠️ Как запустить

1. Скачайте или скопируйте код проекта в один файл с именем `index.html`.
2. Дважды кликните по нему, чтобы открыть в любом современном браузере (Chrome, Firefox, Edge, Safari).

## 📦 Деплой

Этот проект идеален для быстрого размещения на статических хостингах (например, Vercel или Cloudflare Pages) путем простого перетаскивания файла в панель управления.

## 💻 Технологии

* HTML5 / CSS3 (современный и адаптивный интерфейс)
* Vanilla JavaScript (работа с File API, Canvas API и бинарными буферами DataView/ArrayBuffer)
